# 🎬 Netflix Dashboard | Power BI

An interactive Power BI dashboard built using the Netflix Movies & TV Shows dataset to analyze content trends, ratings, genres, countries, release years, and other key insights through interactive visualizations and KPIs.

---

# 📌 Project Overview

This project transforms raw Netflix data into an interactive business intelligence dashboard using Power BI. The dashboard enables users to explore Netflix's content library, understand distribution patterns, and analyze movies and TV shows using dynamic filters and visuals.

---

# 🎯 Objectives

- Analyze Netflix's content library.
- Compare Movies vs TV Shows.
- Identify the most popular genres.
- Analyze content by country.
- Study release year trends.
- Explore ratings and maturity classifications.
- Build an interactive dashboard using Power BI.

---

# 📊 Dashboard Features

- 📈 Total Titles KPI
- 🎬 Movies vs TV Shows Distribution
- 🌍 Content by Country
- 📅 Release Year Analysis
- ⭐ Ratings Distribution
- 🎭 Genre Analysis
- 📆 Year Added to Netflix
- 🔍 Interactive Filters & Slicers

# 📈 Key Insights

- Movies account for a larger share of Netflix's catalog than TV Shows.
- Drama, Comedy, and Documentary are among the most common genres.
- The United States contributes the highest number of titles.
- Most content was released after 2015.
- TV-MA is one of the most frequent content ratings.
- Netflix expanded its content library rapidly in recent years.
